# flowrap

A wrapper-first board for Svelte 5. You don't register node types or
describe your data up front — you wrap a component you already have in a
wrapper that gives it a position and dragging:

```svelte
<FlowNode id="my-card">
  <MyExistingComponent />
</FlowNode>
```

Edges work the same way: `<FlowEdge from to />` is declared next to the
nodes, with no separate `edges[]` array and no type registration. So do
ports: `<FlowHandle>` goes inside a card, and dragging from it ends in an
`onconnect` call on the board.

## Install

```bash
pnpm add flowrap
```

`svelte@^5` is the only peer dependency. There is no CSS file to import —
the core styles live in the components' own `<style>` blocks, and every
visual decision is left to yours.

## The parent must have a non-zero height

`.fr-viewport` is declared as `height: 100%`, which means **you set the
height**. If the wrapper around `<FlowBoard>` has none, the board
collapses to nothing and looks broken — no nodes, no dragging. Every story
here relies on the `.board-host` class (`height: 70vh`) for that.

## Scenarios

Open the **Code** panel next to any canvas — each story's source is the
real explanation, and it is short enough to read end to end.

| Story | What it shows |
|---|---|
| **Showcase / Order pipeline** | the whole library on one screen, light and dark |
| **FlowBoard / Basic** | text, a button and an image inside nodes; drag, zoom, pan |
| **FlowBoard / Zoom limits** | `bind:zoom`, `minZoom`/`maxZoom`/`zoomSpeed`, zoom to cursor |
| **FlowBoard / Many nodes** | 200 nodes, and 200 nodes with 199 edges, as a load test |
| **FlowBoard / Positions sync** | `bind:positions`, saving and loading a layout |
| **FlowNode / Controlled** | controlled vs uncontrolled, `disabled` |
| **FlowEdge / Edges** | three line types, two edges between one pair, a data-driven graph, CSS theming |
| **FlowHandle / Connectors** | ports, dragging connections, `isValidConnection`, ports on four sides |

The same scenarios live in `playground/` as SvelteKit routes — that's what
the Playwright e2e tests point at.
